# Experiment 015: Qwen2.5-1.5B V10 Suite Validation

_Generated by `scripts/run_experiment_015_qwen15b_v10_suites.py`. V11 Phase 1 — larger-model validation on V10 suites._

> This is **larger-model validation**, not a performance benchmark.
> The V10 suites are **stronger and more diverse** than the old 34-prompt `core` suite, but are **still not a universal benchmark**.
> ExactKV preserves the exactness gate: `exactkv_output_ids == full_output_ids`.
> Simulated compressors (`_sim`) are **not** real packed-bit backends.
> `total_kv_footprint_bytes` is a conservative accounting sum, **not** measured peak GPU memory.
> **Active GPU memory is not reported.**
> ExactKV does **not** claim speedup, throughput, latency, runtime, tokens/sec, active GPU memory, or production readiness.

---

## 1. Purpose

Validate whether Experiment **012** findings on V10 suites at **0.5B** transfer to **Qwen/Qwen2.5-1.5B** — same 128 prompts, built-in compressor panel, and anchor settings (`draft_len=4`, `max_new_tokens=16`).

## 14. Whether V10 findings transfer to 1.5B

- **Exactness gate:** `exactkv_failures == 0`.
- **boundary4 vs k8_v4_sim:** boundary4 wins **14** / **128** prompts (ordering largely transfers).
- **int8 vs boundary4:** int8 wins **32** prompts (int8 remains stronger).
- **Hardest suite (pooled):** `retrieval_copy` (mean accept 0.970).

## 15. What this proves

- The exactness gate holds on **128 × 7 = 896** cells at **1.5B** on V10 suites.
- Per-suite and per-category leaderboards are reproducible at larger scale.
- V10 category fragility patterns can be compared directly to Experiment 012.

## 16. What this does not prove

- That V10 suites are universal public benchmarks.
- Production serving, throughput, or latency behaviour.
- That `_sim` compressors are real packed-bit backends.
- That 3B or restricted real backends behave the same (Phase 2).

## 17. Limitations

- Single larger model (1.5B); anchor `draft_len` / `max_new_tokens` only.
- Some categories have low prompt counts (flagged above).
- No KVQuant/TurboQuant/KIVI in this phase (built-in transfer check only).
- RunPod environment; not multi-GPU or production deployment.

## 18. Relation to V11 Phase 2

Experiment 015 completes the **required** 1.5B-on-V10-suites gate. Phase 2 (Experiment 016) may add optional **3B stretch** or **1.5B factory-only real-backend** panel if RunPod budget permits.
